# plan

10주 동안 주차 -> 요일 순으로 하루 일정을 계획하는 데일리 플래너 웹앱입니다.

Next.js(App Router) + TypeScript + Tailwind CSS로 만들었고, 작성한 내용은 브라우저 localStorage에 저장됩니다.

## Getting Started

개발 서버 실행:

```bash
npm install
npm run dev
```

[http://localhost:3000](http://localhost:3000) 에서 확인할 수 있습니다.
